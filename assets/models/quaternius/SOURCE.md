Only the models the editor uses are kept here, from the zip's `glTF` folder, with the textures they reference.
`Leaves_NormalTree_C.png` is also kept because the manifest swaps it in for `Bush_Common`'s pale leaves.

Turn them into the editor's GLB files with `npm --prefix src/web run build:models`. See
`docs/superpowers/specs/2026-11-17-model-library-design.md` and `assets/models/manifest.json`.
