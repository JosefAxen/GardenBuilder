# Katalog – genomförandeplan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Företagets artiklar läses in från Excel till Catalog-modulen, och editorn bygger trädgårdar av dem i stället för en lista i koden.

**Architecture:** Artikelns regler (typmodell, enhet, växtfält) ligger i Catalog-modulens domän. Importen läser en Excelfil med ClosedXML, kontrollerar alla rader och skriver allt eller inget i en transaktion. Den nås via `ICatalogImport` i Contracts, som verktyget `tools/CatalogImport` använder. Verktyget körs som en resurs med manuell start i Aspire. Editorn hämtar artiklarna från `GET /api/catalog/articles` och ritar växter i planteringshöjd.

**Tech Stack:** .NET 10, EF Core med Npgsql, ClosedXML, xUnit v3, Testcontainers, React + TypeScript, zustand, Vitest.

**Spec:** [docs/superpowers/specs/2026-11-14-catalog-design.md](../specs/2026-11-14-catalog-design.md), som bygger på [docs/design.md](../../design.md).

## Global Constraints

- Kod, identifierare, kommentarer och commit-meddelanden på engelska. Allt användaren ser är på svenska, även importfelen.
- Priser är `Money` i SEK inklusive moms, aldrig flyttal. Längder anges i meter. Id:n är UUID v7 (`Ids.New()`).
- Paketversioner står bara i `Directory.Packages.props`. Varningar räknas som fel.
- En modul refererar aldrig en annan modul. Verktyget och AppHost är värdar, inte moduler, och får referera Catalog som Migrator gör.
- Ny migrering: `dotnet ef migrations add <Name> --project src/Modules/Catalog --startup-project src/Api --context CatalogDbContext --output-dir Infrastructure/Migrations`.
- Josef godkänner varje commit och varje push. Stanna vid varje commit-steg, visa filerna och meddelandet, och vänta på ett ja.
- Typmodellnycklar: `deciduous-tree, conifer, shrub, perennial, pot, furniture, hedge, fence, surface-grass, surface-paving, surface-gravel, surface-decking, surface-bed`.
- Excelrubriker: `Artikelnummer, Namn, Sort, Kategori, Enhet, Pris inkl moms (kr), Lagerstatus, Typmodell, Skala, Färg, Accentfärg, Växtzon, Höjd (m), Bredd (m), Fullvuxen höjd (m), Fullvuxen bredd (m), Klipphöjd (m), Tillväxt (cm/år), Ljus`.
- Enheter i Excel: `st`, `m`, `m²`. Lagerstatus: `I lager`, `Slut`, `Utgått`. Ljus: `sol`, `halvskugga`, `skugga`, kommaseparerade.

## Review Focus

1. Excelceller som Excel har sparat som tal och celler som är text, till exempel pris `1295,5`, `1 295,50` och `1295.50`, ska ge samma pris. Testas i Task 3.
2. Tomma rader mitt i eller sist i bladet ska hoppas över, inte ge fel. Testas i Task 3.
3. Samma fil importerad två gånger ska inte ge dubbletter. Id:n ska vara oförändrade och resultatet ska säga 0 skapade. Testas i Task 4.
4. Om katalogen inte går att hämta, eller om scenen pekar på en artikel som inte finns i katalogen (till exempel utgången), ska editorn visa ett svenskt meddelande eller hoppa över elementet. Den får inte krascha. Testas i Task 6.
5. Rubriker med annan skiftläge eller extra mellanslag (`artikelnummer `) ska kännas igen. Testas i Task 3.

  - `sealed record CatalogImportError(int Row, string Column, string Message)`
  - `sealed record CatalogImportResult(int Created, int Updated, int Discontinued, IReadOnlyList<CatalogImportError> Errors)` med `bool Succeeded => Errors.Count == 0`
  - `interface ICatalogImport { Task<CatalogImportResult> ImportAsync(Stream xlsx, CancellationToken cancellationToken); void WriteExample(Stream xlsx); }`

Om arket har fel skrivs ingenting, och resultatet bär felen med 0 i alla räknare. Annars görs allt i en transaktion (`Database.BeginTransactionAsync`):
- Artiklar matchas på artikelnummer. Finns numret anropas `Update`, annars `Create`.
- Artiklar som finns i databasen men inte i filen får `Discontinue`, om de inte redan har den statusen.
- `Updated` räknar bara artiklar vars data faktiskt ändrats.
