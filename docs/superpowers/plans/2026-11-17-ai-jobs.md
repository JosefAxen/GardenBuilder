# Jobbkö och AI-ramverk Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A PostgreSQL job queue in the AI module that the Worker runs with row locks, leases, three attempts, a cost log, per-garden quotas, per-step switches and a daily budget, proven end to end by an admin "Testa AI-anslutningen" job that calls Claude.

**Architecture:**
- `ai.jobs` holds the queue and `JobQueue` claims with `FOR UPDATE SKIP LOCKED`. `JobRunner` runs one claimed job through a registered `IAiJobHandler` and records every provider call in `ai.calls`.
- Guards (budget, switches, missing price, missing key) run before each call. Claude sits behind `ITextModel`, using the official `Anthropic` NuGet package; tests use a fake.
- The API enqueues and reads jobs and settings; only the Worker hosts the processor and the Claude client.

**Tech Stack:** .NET 10, EF Core + Npgsql, xUnit v3 + Testcontainers, `Anthropic` C# SDK, React + vitest.

**Spec:** `docs/superpowers/specs/2026-11-17-ai-jobs-design.md`

## Global Constraints

- **Keys and processes:**
  - Only the Worker calls AI providers and reads `Anthropic:ApiKey`.
  - `AddAiJobProcessing` and the Claude client are registered in the Worker only, never in the API.
- **Data:**
  - Ids are `Ids.New()` (UUID v7). Times are UTC via `TimeProvider`. Money is `Money` in SEK.
  - Tables and columns are snake_case in schema `ai`. Migrations are made via `dotnet ef ... --context AiDbContext`.
- **Queue:**
  - Lease 5 minutes; at most 3 attempts.
  - Retry after 10 s (after attempt 1) and 60 s (after attempt 2).
  - Workers poll every 2 s, one job at a time.
- **Defaults:**
  - Daily budget 500 kr.
  - Quotas: `photo-interpretation` 3, `design-proposal` 5, `dream-image` 5.
  - All three steps on.
  - Day = Europe/Stockholm calendar day.
  - Budget warning at 80 % (log only).
- **Pricing:**
  - `Ai:Prices:claude-opus-5-5` is input 4, output 20 USD per million tokens.
  - `Ai:UsdToSek` 10.50.
  - `Anthropic:Model` default `claude-opus-5-5`.
- **Job kinds:** `connection-test`, `photo-interpretation`, `design-proposal`, `dream-image`. Only `connection-test` has a handler now. Prompt version `connection-test@1`.
- **Copy (Swedish, exact):**
  - "Ingen API-nyckel för Claude är inställd."
  - "AI-stegen är pausade för i dag."
  - "Det här AI-steget är avstängt."
  - "Modellen {model} saknar pris i inställningarna."
  - Connection-test prompt: "Svara med en mening på svenska: vad är en trädgård?"
- **Not in scope:** the e-mail confirmation requirement, alarms, Gemini or image models, and server-side refusal fallbacks (a refusal is a failed attempt).

## Review Focus

1. **Two Workers polling at once.** Each job is claimed by exactly one. Test in Task 1.
2. **A Worker that dies mid-job.** The job is claimable again after its lease; after the third attempt it ends `failed`, not stuck `running`. Test in Task 1.
3. **The budget reached while jobs wait in the queue.** Those jobs fail with "AI-stegen är pausade för i dag." without a provider call. Test in Task 3.
4. **A Claude answer cut off (`max_tokens`) or refused.** The answer is logged as a failed call with its cost, and the job is retried. Test in Task 3.
5. **A non-admin (sales staff, customer, anonymous) calling the settings or test endpoints.** 403 or 401, and nothing is changed or queued. Test in Task 4.
